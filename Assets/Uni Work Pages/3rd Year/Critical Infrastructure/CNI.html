Critical National Infrastructure Security

This module investigates security challenges within Critical National Infrastructure (CNI), focusing on vulnerability assessment and threat analysis in high-risk operational environments. The objective is to examine real-world security risks, assess organisational resilience, and apply red teaming principles to evaluate security posture. Technical focus includes risk analysis, security assessment methodologies, and lessons learned from infrastructure-based case studies.

Executive Summary

This project explores security risks within CNI domains, with particular emphasis on vulnerability assessment and threat mitigation strategies. The work analyses organisational security postures and demonstrates red teaming methodologies applied to infrastructure environments. Outcomes highlight critical security lessons and recommendations for strengthening operational resilience and risk management.
